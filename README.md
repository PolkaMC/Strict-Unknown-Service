# Strict-Unknown-Service

This game is called "Criminal"

You are given a character to find in a sea of different characters. 

You are also given a timer, but it has no time. It is just going down very fast.

If you find the criminal, you are given a point. Else, GAME OVER.

Everything in this game is custom. Custom graphics and character design.

This game is co-developed with Polka and Markian Gorbal
